# beax 标准文档

**crate**：`beax` v0.1.0 | **来源**：`specs/adapter/bea.md`（source_id = `bea`）| **状态**：非 package stable

**能力标准**：本库以类型化形式表达 BEA 源事实，并提供离线解析、跨源守卫与 fail-closed
授权判定。**它不是联网采集器**，不实现 live 与官方 PIT，`production_decision = NO-GO`。

## 1. 源事实与采集范围标准

- Dataset 全集 = 清单登记的 **11 个**：`NIPA`（**P0**）、`NIUnderlyingDetail`、`FixedAssets`、
  `ITA`、`IIP`、`IntlServTrade`、`GDPbyIndustry`、`UnderlyingGDPbyIndustry`、`InputOutput`、
  `Regional`、`MNE`（后 10 个为 keep-P1）。
- Dataset 优先级：`NIPA` = 0，其余 10 个 = 1（`dataset_priority`）。
- 清单范围外的 Dataset MUST NOT 被本库接受（`ensure_known_dataset` 原子拒绝）。
- 清单未登记非 NIPA 数据集的明细表号（自述「明细为历史材料，未入库」），
  故本库 MUST NOT 为其编造表号；夹具与测试中该类表号一律用 `SYN-` 前缀的**合成占位串**。

## 2. 值与期间标准

- `Date { year: i16, month: u8, day: u8 }`：年份 `1..=9999`、月 `1..=12`、日按月份与闰年校验。
- `Period`：`Day` / `Month` / `Quarter` / `Year` / `Event`；`quarter` ∈ 1..=4。MUST NOT 用字符串顶替。
- `Frequency`：`daily` `weekly` `monthly` `quarterly` `annual` `event` `irregular` 七个记号，
  **只接受小写**。
- 值形态 `BeaValue`：`Present(f64)` 或 `Missing(BeaMissingReason)`；缺失 MUST 具名表达，
  MUST NOT 静默折算为 `0`。`Present` 的值 MUST 为有限数（NaN / 无穷被拒绝）。
- 观测 `BeaObservation`：身份 = `dataset_id` + `table_id` + `line_number` + `period` + `vintage`；
  `line_number` MUST ≥ 1；`vintage` 无官方面时为 `None`，MUST NOT 伪造。
- 表号 MUST NOT 被直接当作指标 ID（`source_series_id` 保留原始表号 / 行号）。
- 公开校验入口：`validate_date` / `validate_period` / `validate_observation`。

## 3. 表级白名单与优先级标准

- NIPA 表级白名单 = **P0 2 表**（`T10101` `T20100`）+ **P1 12 表**
  （`T10102`–`T10107`、`T10201`、`T20301`、`T30100`、`T40100`、`T50100`、`T70100`），共 **14 表**。
- 表级优先级：P0 表 = 0，P1 表 = 1（`table_priority`）。**未从白名单删除任何表**。
- 当且仅当 `dataset_id == NIPA` 时，表号 MUST ∈ 白名单（`ensure_nipa_table`）；
  非 NIPA 数据集不使用 NIPA 白名单。
- 表级频率：清单只对 `T10101`（季频）与 `T20100`（月频）声明了频率；
  `ensure_table_frequency` 对这两表做一致性判定，其余表 MUST NOT 由实现方推定。

## 4. 跨源守卫标准（曲线路由 / 核心 PCE 主责 / 禁静默替换）

- **曲线产品拒绝**：BEA 曲线类产品 MUST NOT 自动进入本域，须路由 `yieldx`
  （`CURVE_BUILD_OWNER`）。`ensure_claim_local(BeaClaim::YieldCurveConstruction)`
  一律返回 `RoutedElsewhere`。
- **核心 PCE 主责在 `fredx`（fred-forward）**：`PCEPILFE` 的采集主责是 `fredx`，
  本域的表内 PCE 行只是**补充口径**。`ensure_claim_local(BeaClaim::CorePcePrimary)`
  一律返回 `WriteAuthorityDenied`，MUST NOT 反向主张、MUST NOT 静默替换身份。
- 本域可主张的身份只有 `BeaClaim::SupplementaryTableValue`。
- `NEAR_SYNONYM_PAIRS` 登记 `cross-source-routing.md` §4 中**涉及 beax 的 6 对**：
  `GDPNow`≠`GDP`、`PCEPILFE`≠`PCEPI`、`T20100`≠`PCEPILFE`、`T20100`≠`T20300`、
  `T20100`≠`T20600`、`GDP`≠`GDI`。`ensure_not_silent_substitution` 对其**双向**判定：
  命中即 `SemanticallyRejected`。
- `T11000` 是 GDI 的**候选**表（待 live 核验），MUST NOT 被表述为已入白名单；
  `T20300` / `T20600` 与 `T20100` 语义不同，MUST NOT 互换。

## 5. publication 语义标准

- `bea_publication_semantics()` 恒返回 `(Date, Inferred, NotEligible)`。
- `is_formal_pit_eligible()` **恒为 `false`**（对应清单的
  `macro_bea::assemble_bea_observations` 口径）：BEA 无官方 vintage 面
  （源级例外 `PIT-EXCEPT-BEA-001`），离线 fixture 无发布时刻字段。
- MUST NOT 补造 `08:30 ET` 之类时刻把 `Date` 伪装成 `Instant`；日后若接入官方 vintage 面
  或经核验的官方发布日历，MUST 先改清单与契约，**禁止静默升格**。

## 6. 授权判定标准（fail-closed，live 不被覆盖）

- 已登记证据：`BEA-PROD-2026-08-17-approve`（签署者 `ZoneCNH`），
  `scope = offline_and_reference_only` —— 覆盖 `Offline` 与 `ReferenceOnly`，
  **不覆盖 `Live`**；同时登记 `accept_no_pit = true`、`live_official_pit = NO-GO`。
- `authorize_bea` 的判据：证据缺失 / 签核编号不明 / 签署者不明 / 覆盖范围不明 / 已过期 /
  请求模式不在覆盖集合内 → **一律 `Denied`**，MUST NOT 默认放行。
- 判定 MUST NOT 改写清单原登记值；判定的是「该源的这个范围是否被授权访问」，
  **不是**「本库是否生产就绪」。
- 评估日期 `as_of` 由调用方传入，本层**不读取系统时间**。

## 7. 离线解析标准

- 入口 `parse_bea_observations(input: &str)` **只接受字符串**，MUST NOT 接受 URL、
  HTTP 客户端、认证信息或任何网络参数。
- 输入形态为本库自定的 JSON 对象：`{ "_synthetic"?, "_note"?, "records": [ … ] }`，
  每条记录 `{ dataset_id, table_id, line_number, date, value, unit, frequency, vintage? }`。
  `_synthetic` / `_note` 是**已知字段**（合成样本标注），不是未知字段。
- **未知字段原子失败**（顶层或记录层出现未知键 → 整体失败，MUST NOT 静默忽略）。
- **重复身份选择「拒绝」**（不去重）：同一 `dataset_id` + `table_id` + `line_number` +
  期间 + `vintage` 出现两次即 `SemanticallyRejected`。
- 值形态：JSON 数值 → `Present`；`"."` 或 `null` → `Missing(NoObservation)`；其余 → 拒绝。
- 期间投影：按清单频率把源日期投影为该频率的期间身份（日/周/不规则 → `Day`；
  月 → `Month`；季 → `Quarter`；年 → `Year`；事件 → `Event`）。这是**期间投影**，不是派生指标。
- 解析错误消息只报告行列位置，MUST NOT 回显输入内容。

## 8. 合成夹具声明

`tests/fixtures/` 下的全部夹具（`bea_observations_synthetic.json`、
`bea_nipa_tables_synthetic.json`）都是**合成样本**：由特性 005 自拟，**不是真实源数据，
不构成任何证据**，MUST NOT 被表述为「实测」「核验 PASS」或任何证据等级。每个夹具文件在
顶层带 `"_synthetic": true` 与 `"_note"` 标注。清单未逐表声明源单位，故 `unit` 取值为
**合成占位串**；非 NIPA 数据集的表号用 `SYN-` 前缀占位，二者均不得当作源事实。

## 9. 依赖与零网络标准

- 依赖仅 `thiserror` / `serde`（`derive`）/ `serde_json`；
  MUST NOT 引入任何 HTTP 客户端、异步运行时、`chrono` / `time`、`rand`。
- 源码 MUST NOT 出现 `https://…` 端点字面量，MUST NOT 读取环境变量或凭据，
  MUST NOT 配置代理。
- MUST NOT 依赖任何 `bytechainx/*` crate（含 `path` 依赖）；本库与兄弟库的形状**各自实现一遍**，
  MUST NOT 新建共享 core crate。
- 非测试路径 MUST NOT 出现 `unwrap()` / `expect()` / `panic!` / `println!` / `dbg!`。

## 10. 端点与凭据不入库标准

- 端点的具体 URL、认证参数名、限流数字与凭据字段名 MUST NOT 进入本库的源码、文档与夹具：
  它们属**规划描述**，不是访问合同（相关值亦不在本清单中）。
- 本库 MUST NOT 读环境变量、写凭据字段、或把凭据拼进任何错误消息。
- 采集侧凭据策略与限流合同归采集实现，不属本层。
